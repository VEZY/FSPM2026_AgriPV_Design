# Design of experiment (DOE)

panel_length is in the y-cartesian axis
panel_width is in the x-cartesian axis

- 0..5: Tilted at 25°, South-oriented, with variable x gap between panels
- 6..11: Flat, South-oriented, with variable x gap between panels
- 12..17: Flat, East-oriented, with variable x gap between panels
- 13..89: Same as all previous ones with variable height
